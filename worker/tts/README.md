# ClipWaltz voice service

Kokoro-82M TTS (Apache-2.0 code + weights) as a localhost HTTP service on the render box (`ai`), used by the
render worker for WaltzDeck voiceovers + word-timed captions. See ADMIN_DOCS.md "WaltzDeck voice & captions".

Install (done 2026-09-29): `/opt/clipwaltz-tts` — `uv` (from PyPI in `.uvboot`) → Python 3.12 venv (kokoro 0.9.4
requires <3.13) → `torch` CPU wheel + `kokoro==0.9.4 soundfile fastapi uvicorn pip` (pip lets spaCy fetch
`en_core_web_sm`). Unit: `/etc/systemd/system/clipwaltz-tts.service` (User=lacy, 127.0.0.1:8191, TTS_THREADS=8,
HF_HOME=/opt/clipwaltz-tts/hf). Deploy: copy `server.py` to `/opt/clipwaltz-tts/` and `systemctl restart clipwaltz-tts`.

Voice previews in `public/voices/*.mp3` were generated by this service (same sentence per voice).
